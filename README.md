Bienvenue sur le dépôt officiel de l'application **OxyONE**, la solution digitale intelligente dédiée à la gestion, la supervision et l'optimisation des infrastructures de la chaîne du froid et de l'industrie du futur.

---

## 📌 À propos du Projet

**OxyONE** s'inscrit dans la continuité des travaux issus de l'ouvrage *"L'Usine du Futur dans le Secteur du Froid"*. La plateforme combine des fonctionnalités IoT, le suivi en temps réel et l'analyse de données pour offrir une visibilité globale et un contrôle accru sur les équipements frigorifiques modulaires et mobiles.

### Fonctionnalités Clés
- 🌡️ **Monitoring IoT en temps réel** : Suivi continu des températures, de l'hygrométrie et des performances énergétiques.
- 🚚 **Digital Sense & Smart Tracking** : Traçabilité complète des unités mobiles et de la chaîne du froid.
- 📊 **Tableaux de bord analytiques** : Visualisation des performances opérationnelles et alertes préventives.
- ⚙️ **Architecture Scalable** : Conçu pour s'adapter aux exigences de l'industrie 4.0.

---

## 🛠️ Stack Technique

- **Frontend** : React / TypeScript / Tailwind CSS
- **Backend** : Node.js / Express
- **Base de données / IoT** : Firebase / REST APIs
- **Déploiement & Cloud** : GitHub / Replit / Cloud Shell
